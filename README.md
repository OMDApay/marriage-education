# دليل التثقيف الزواجي - موقع تعليمي للشباب المقبل على الزواج

## نظرة عامة
تم إنشاء موقع إلكتروني تعليمي شامل يهدف إلى تثقيف الشباب المقبل على الزواج حول الجوانب المختلفة للحياة الزوجية، مع التركيز بشكل خاص على التثقيف الجنسي بطريقة علمية ومحترمة.

## مميزات الموقع

### التصميم والواجهة
- تصميم عصري ومتجاوب مع جميع الأجهزة
- واجهة باللغة العربية مع دعم كامل للكتابة من اليمين إلى اليسار
- ألوان هادئة ومريحة للعين
- تنقل سهل وبديهي بين الأقسام المختلفة

### المحتوى التعليمي
1. **مقدمة عن الحياة الزوجية**
   - أهمية التثقيف الزواجي
   - التواصل كأساس للنجاح
   - أهداف الموقع

2. **التشريح والفسيولوجيا**
   - الجهاز التناسلي الذكري مع رسوم توضيحية
   - الجهاز التناسلي الأنثوي مع رسوم توضيحية
   - شرح الوظائف الأساسية

3. **دليل الأوضاع الجنسية**
   - الأوضاع الأساسية مع رسوم توضيحية محترمة
   - نصائح للمبتدئين
   - إرشادات الأمان والراحة

4. **النصائح والإرشادات**
   - النظافة الشخصية
   - الاستعداد لليلة الأولى
   - التعامل مع القلق والتوتر
   - متى نطلب المساعدة المهنية

5. **الأسئلة الشائعة**
   - إجابات على الأسئلة الأكثر شيوعاً
   - نصائح للحصول على المساعدة المهنية

### المبادئ التوجيهية
- محتوى علمي ودقيق من مصادر موثوقة
- لغة محترمة ومهنية
- صور تعليمية غير إباحية
- احترام الثقافة والقيم الإسلامية
- التركيز على الجانب التعليمي والصحي

## التقنيات المستخدمة
- **React.js** - إطار العمل الأساسي
- **Tailwind CSS** - للتصميم والتنسيق
- **Shadcn/UI** - مكونات واجهة المستخدم
- **Lucide React** - الأيقونات
- **Vite** - أداة البناء والتطوير

## كيفية تشغيل المشروع

### المتطلبات
- Node.js (الإصدار 18 أو أحدث)
- npm أو pnpm

### خطوات التشغيل
1. انتقل إلى مجلد المشروع:
   ```bash
   cd marriage-education-website
   ```

2. قم بتثبيت التبعيات:
   ```bash
   npm install
   # أو
   pnpm install
   ```

3. شغل خادم التطوير:
   ```bash
   npm run dev
   # أو
   pnpm run dev
   ```

4. افتح المتصفح على العنوان: `http://localhost:5173`

### البناء للإنتاج
```bash
npm run build
# أو
pnpm run build
```
